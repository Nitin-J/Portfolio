# Nitin Joshi Portfolio

Static portfolio for GitHub Pages.

## Files

- `index.html` - main portfolio page
- `styles.css` - responsive styling
- `script.js` - mobile navigation and header behavior
- `assets/backend-systems-hero.png` - generated hero visual
- `assets/nitin.png` - profile photo
- `assets/Nitin_Joshi_SDE_Resume.pdf` - downloadable resume

## Run Locally

Open `index.html` directly in a browser, or from this folder run:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Deploy To GitHub Pages

1. Push the `portfolio` folder to a GitHub repository.
2. In repository settings, go to **Pages**.
3. Set the source to the branch that contains this folder.
4. If GitHub Pages must serve from the repository root, move the contents of `portfolio` to the root of that repo.

No build step is required.
